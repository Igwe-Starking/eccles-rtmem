# Code of Conduct

We want this project to be a friendly place to learn and build embedded software.

**Do:** be respectful, assume good faith, give specific and kind feedback, and welcome newcomers, including people who are new to C or to microcontrollers.

**Don't:** harass, insult, or demean anyone; post other people's private information; or use the project's spaces for personal attacks or discriminatory language.

Maintainers may edit, hide, or remove comments, issues, and contributions that break these rules, and may ban repeat offenders.

To report a problem, contact the maintainer through the email listed on their GitHub profile. Reports are handled privately.

This code applies in all project spaces (issues, pull requests, discussions) and when someone is representing the project in public.
