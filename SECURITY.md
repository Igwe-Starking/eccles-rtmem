# Security Policy

## Reporting a vulnerability

Please **do not** open a public issue for a memory-safety bug or anything exploitable.
Use GitHub's private reporting instead: **Security → Report a vulnerability** on this repository.

Include the configuration macros you used, a minimal call sequence that triggers the problem, and your target/toolchain.
You'll get an acknowledgement as soon as I can, and credit in the changelog if you'd like it.

## Supported versions

Only the latest release receives fixes.
